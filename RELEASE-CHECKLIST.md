# SYNAPS 0.5.0 strict release checklist

This audit compares the attached Russian brief with the source that was changed in this work session. “Implemented” means source behavior exists, not that a desktop build or live provider was verified. This is not a release certification.

## Requirement-by-requirement audit

1. **Product philosophy and visual system — PARTIAL.** Dark engineering styling retained and refined. Settings now apply interface scale, compact/comfortable density, standard/high contrast and motion preference. Fine-grained font family exists. Full appearance options (transparency, blur, theme modes, font scale variants) are not all implemented.
2. **Original SYNAPS identity — IMPLEMENTED IN SOURCE.** New geometric node-link mark and wordmark are original vector work; rail mark, top-bar wordmark, favicon, Windows ICO and app PNG are replaced. The supplied Anthropic image was treated as inspiration only, not traced or copied. Inspect on Windows title bar/taskbar before release.
3. **Graph workspace — PARTIAL.** Typed ports, move, delete, copy/paste, shift multi-select and group drag, named grouping, persisted 50–140% wheel/button zoom and reset are in source. It is not infinite-canvas, node resize/compact mode, arbitrary alignment, a real minimap control, or full graph group-frame editing.
4. **Node library and execution — PARTIAL.** Legacy catalog is preserved and unsupported operations fail explicitly. The runner remains a limited explicit subset; broad data/RAG/logic/tool/monitoring node executors, node configuration and complete error states are missing. Unsafe Python/arbitrary file execution is not enabled.
5. **Seven-level Effort — IMPLEMENTED, PROVIDER SUPPORT PARTIAL.** All seven modes, adaptive heuristic and output-budget mapping are implemented and unit-tested. Generic reasoning parameter is opt-in; provider capabilities are not negotiated and profiles do not guarantee deeper model reasoning.
6. **Neural Visualizer — NOT IMPLEMENTED.** Actual layer activations/3D telemetry are unavailable. Inspector reports measured client/provider data only. Do not market the inspector as layer visualization.
7. **LLM Activity — PARTIAL.** Activity panel presents observed trace and reported metrics, with no fake chain-of-thought. It is not a movable, pinnable/resizable floating window and does not expose backend hardware telemetry.
8. **LLM Lab — PARTIAL.** First-entry warning and local project-save backup exist. For Ollama, it now creates a genuinely separate model tag via `/api/create`, derived from the selected base and persisting system instructions, stop sequences and validated sampling/context settings; the base tag is never overwritten. This changes the model's saved behavior/configuration, not its neural weights. No fine-tuning/LoRA, weight editing, tokenizer/architecture change, config diff/rollback, or low-level source browser.
9. **Video Analysis — PARTIAL.** Local still-frame sampling (up to eight resized frames) can be sent to a selected image-capable local model. It does not analyze audio, continuous motion, object detections as verified labels, or native video input. Decoder/provider path still needs WebView QA.
10. **Extended settings — PARTIAL.** Provider, sampling, theme palette/font, scale, density, contrast, motion, prompts and project options exist. Privacy/security settings explain local limits. Full settings breadth, context policies, fallbacks, queue controls, blur/transparency and theme system are incomplete.
11. **Application password — PARTIAL / NOT DATA ENCRYPTION.** Password gate verifies salted PBKDF2-SHA256 before hydrating local project/chat state, and clears the working React state when locked. Recovery uses a one-time recovery code. localStorage and SQLite are not encrypted, there is no OS secure storage, and it does not protect a compromised device profile. Never advertise it as a secure vault.
12. **Chat Center — PARTIAL.** Local model streaming, on-device history, search, pin, rename, delete, Markdown export, edit-from-turn, retry, stop, system prompt, model/Effort, safe Markdown rendering and capped local image attachment exist. No cloud provider, document/video attachment, in-place edit UI, or live cancellation verification.
13. **Model Hub — PARTIAL.** Pulls a manually entered tag through a loopback-only local Ollama instance and shows the installed inventory. No online/searchable catalog, metadata/license/size/RAM estimate, mirror picker, folder destination selection, or other-provider installers.
14. **Download Center — PARTIAL.** Persists Ollama pull and derived-model creation jobs, displays provider-reported status/byte progress where available, supports cancel/retry, and offers no invented speed/ETA. Ollama exposes no pause/resume API in this implementation; provider may retain partial blobs. No custom destination management.
15. **API Connections/key center — NOT IMPLEMENTED.** Build is loopback-only and stores no provider API keys. No cloud provider adapters or operating-system credential vault.
16. **SYNAPS Assistant — NOT IMPLEMENTED.** No connected cloud model or assistant that proposes/obtains approval for app changes.
17. **Partial-result handling — PARTIAL.** Experiment results preserve per-model errors and received response. Streaming graph/chat can display received text, but comprehensive resumable task state, continuation and model-switch recovery are not implemented.
18. **Guide/Knowledge Base — PARTIAL.** Practical guide covers setup, local/cloud boundary, Effort, graph, model profiles, video sampling, security and real-vs-unavailable telemetry. It is not yet the full onboarding/manual requested.
19. **Additional product capabilities — PARTIAL.** Local model profiles, multi-model Experiment Lab, project recents/versioning and diagnostics exist. No user-rated benchmark scoring, session crash recovery, GPU/RAM/VRAM diagnostics or isolated per-project credentials/workflows.
20. **Engineering quality and test evidence — PARTIAL.** Explicit limitations and loopback checks remain. Fourteen Node unit tests pass and esbuild JSX/browser bundle succeeds. Browser interaction, official Vite build, Cargo/Tauri compile, Ollama pull integration, provider streaming and Windows installer are not verified here.

## Release gate

**Do not publish as a complete fulfillment of the brief.** First obtain a clean Windows build and installer, run the UI and provider workflows on Windows, test video codecs, check taskbar/title-bar icon and animations under reduced-motion, and verify the password/recovery experience. If publishing a scoped early-access build, clearly label the product as local-first and partial; omit claims of Neural Visualizer, full model catalog/download manager, cloud API keys, protected data-at-rest, full video understanding, or complete graph runtime.
