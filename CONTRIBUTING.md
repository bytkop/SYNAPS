# Contributing

1. Open an issue describing the change and its user impact.
2. Keep changes scoped and document limitations honestly.
3. Do not add telemetry, credential collection, model weights, or external network calls without an explicit privacy/security design.
4. Add or update tests for behavior changes. Never fake model data or provider status.
5. Test `npm run build`; on Windows, test `npm run tauri -- build` before proposing packaging changes.
6. Submit a pull request with test results and screenshots for UI changes.
